Behind the Studio

Human-directed.
Machine-assisted.

AI makes the footage. A person decides what it should be, rejects what isn't good enough and finishes what is. This is how the studio actually works, from the first idea to the posted film.

Human

Creative direction

  • Concept and story beats
  • Shot-by-shot script: framing, angle, lens, camera movement
  • Character and world design, locked in a style bible
  • Keyframe approval before anything is animated
Automated

AI production

  • Claude plans shots and orchestrates the run
  • Runway API generates keyframes and motion
  • Automated quality checks on every shot
  • Python and FFmpeg assemble the picture
Human

Finishing

  • Frame-by-frame review of every take
  • Music selection and sound design
  • Edit, grade and export in DaVinci Resolve
  • Final approval. Nothing posts without it.
The pipeline

From script to screen

Eight stages. The automated ones run on GitHub Actions; the human ones are where the film actually gets made.

01

Script

Story beats become a shot list with framing, angle, lens, movement, and start and end frames.

Rishi · Claude
02

Design refs

Characters and locations are generated once, approved, and locked as references.

Nano Banana Pro
03

Keyframes

One keyframe per shot, built from the locked references and approved before animation.

Runway API
04

Shots

Each keyframe is animated with a single reference, plus an end frame for long moves.

Kling 4 via Runway
05

Quality check

Frames are sampled and checked for drift, morphing, extra limbs and broken physics.

Claude vision · checklist
06

Assembly

Shots are trimmed, joined and scaled to a picture-only cut, ready for sound.

Python · FFmpeg
07

Review

Previews land in a GitHub issue. Each shot gets an /ok or a /redo with a reason.

Human approval
08

Finish & post

Music, sound, grade and export, then published with honest AI labels.

DaVinci · YouTube · X

Every /redo reason is logged and fed back into the next script and the quality checklist.

The stack

What each tool is for

Intelligence

Claude

Writes shot lists and prompts, checks frames against the quality checklist, and helped build the pipeline itself.

Orchestration

GitHub Actions

Runs every production job, keeps API keys in Secrets, and stores every episode, prompt and preview under version control.

Generative media

Runway API

One API for image and video models: Nano Banana Pro for designs and keyframes, Kling 4 for motion, plus Seedance 2 and Gen-4.5 for tests.

Assembly

Python & FFmpeg

Deterministic editing: trims, joins, scaling, end cards and loudness checks. The same input always gives the same cut.

Finishing

DaVinci Resolve

Where a human takes over: music, sound design, grade and the final vertical export.

Distribution

Google Cloud

OAuth for the YouTube Data API, so approved films can be uploaded straight from the pipeline.

Quality bar

Three gates. Every film.

A written checklist every production has to pass. When something gets rejected, the reason becomes a new rule.

Gate 1

Keyframe

  • Characters match their locked designs
  • No duplicates or extra people in frame
  • Framing and angle match the script
  • Continuity with the previous shot
Gate 2

Shot

  • No morphing, flicker or extra limbs
  • Physically plausible: nothing walks through solid objects
  • Camera movement looks intentional
  • Models only switch at a cut
Gate 3

Final cut

  • The first two seconds hook
  • The story reads in one viewing
  • The ending lands
  • Sound at streaming loudness, no clipping
